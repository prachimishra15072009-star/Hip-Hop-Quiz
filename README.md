Hustle Quiz : Hip-Hop CLI Quiz Game
A command-Line interface (CLI) trivia game built in C++ that tests your knowledge of Hip-Hop culture , terms , and * MTV Hustle * history .

Features ;
-- User Authentication : a simple player name login to personalize the quiz run . -- step by step instruction shown before starting -- 15-Question challenge : multiple choice question covering hip-hop fundamentals , slang/mechanics and MTV Hustle trivia . -- ** Scoring system ** : +1 for correct answer : No negative marking : passing score threshold set at ** 10/15 ** with dynamic pass/fail results . -- **Replay loop : ** Option to restart and play again immediately after finishing a run .

Requirements ;
-- GITHUB to copy the code. -- C++ compiller (mingw). -- visual studios to run the code
